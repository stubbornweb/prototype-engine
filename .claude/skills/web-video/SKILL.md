# Web Video

Use video when passive cinematic movement is more efficient or visually appropriate than realtime rendering.

Provide:
- poster image
- muted autoplay/playsinline behavior when appropriate
- mobile fallback
- reduced-motion/static treatment
- compressed web delivery

Keep the subject/composition stable enough for typography to remain readable.
