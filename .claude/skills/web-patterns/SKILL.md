# Web Patterns

Search `patterns/` before inventing a new interaction.

A reusable pattern defines:
- visual intent
- layout/composition
- motion
- inputs/variants
- responsive behavior
- performance constraints
- agent implementation recipe

When a prototype contains a repeatable technique worth keeping, use `prototype-engine extract-pattern` and then clean the pattern into an independent recipe.
