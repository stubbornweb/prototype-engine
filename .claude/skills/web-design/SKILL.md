# Web Design

Create a design contract before implementation:
- visual concept
- emotional effect
- typography direction
- color strategy
- density and negative space
- hero composition
- section rhythm
- motion language

Avoid generic SaaS layouts, random gradients, arbitrary glassmorphism, and animation without a purpose.

Borrow patterns, not identities. A reference is input to a new composition, not something to reproduce literally.
