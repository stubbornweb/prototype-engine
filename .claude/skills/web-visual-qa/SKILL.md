# Visual QA

Use Playwright when available.

Review at minimum:
- desktop 1440×900
- mobile 390×844

Inspect:
- hero hierarchy
- typography
- whitespace
- CTA visibility
- object/visual placement
- motion timing
- overflow/clipping
- loading state
- reduced motion
- console errors

Fix the three most visible problems first. Repeat the screenshot/inspect/fix loop until the result is demo-ready.
