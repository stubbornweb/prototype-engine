# Agent Recipe — Cinematic Hero

Use this recipe when the page needs a strong first viewport but does not require an interactive 3D object.

## Composition
- full-height hero
- large editorial headline
- atmospheric media layer
- short supporting copy
- single primary CTA

## Motion
- staged entrance
- slow media movement
- no perpetual UI bounce

## Responsive
- preserve headline hierarchy
- replace heavy video/3D with poster/static treatment on constrained devices when necessary

## Implementation order
1. HTML/content hierarchy
2. typography and spacing
3. visual media
4. Motion
5. responsive tuning
6. QA
