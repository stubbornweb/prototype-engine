# Prototype Loop

The first production target is not "one prompt, one generation". It is "one user request, autonomous multi-pass execution".

```text
brief
  ↓
design direction
  ↓
pattern selection
  ↓
asset decision (DOM / 3D / video)
  ↓
implementation
  ↓
run browser
  ↓
visual QA
  ↓
fix biggest issues
  ↓
publish
  ↓
extract pattern
```

A good prototype is intentionally narrower than a client-ready site.
