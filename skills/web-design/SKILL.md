# Web Design

Start from the customer contract in `EXPERIENCE.md` (`${CLAUDE_PLUGIN_ROOT}/docs/customer-first.md` §1). The visual direction exists to make that offer clear, credible, and easy to act on — and to look current and memorable while doing it.

Create a design contract before implementation:
- visual concept — and which customer question it helps answer
- message hierarchy: H1 names the offer/outcome, primary CTA above the fold, proof next to the ask
- emotional effect
- typography direction
- color strategy
- density and negative space
- hero composition
- section rhythm
- motion language

Distinctive is a tool, not the goal. Ask of every flourish: would a buyer notice it helped, or only a designer?

Avoid generic SaaS layouts, random gradients, arbitrary glassmorphism, and animation without a purpose.

Borrow patterns, not identities. A reference is input to a new composition, not something to reproduce literally.
